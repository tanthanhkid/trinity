# Commercial offerings

Trinity is free under AGPL-3.0. Thanh, the creator, also offers paid options for companies that want more.

| Option | For whom | What you get |
|---|---|---|
| **Self-hosted (free)** | Teams with technical staff | Full source code, community support |
| **Trinity Cloud** | Companies that don't want to run servers | Hosted, private server per company, updates, backups, monitoring |
| **Implementation & customization** | Companies with specific processes | Setup, data migration from Excel/other software, custom screens, integrations (Zalo, e-invoice, accounting, e-commerce…) |
| **Commercial license** | Software vendors and companies that cannot accept AGPL | Use Trinity in closed-source products, no obligation to publish changes |
| **Support plans** | Companies running Trinity in production | Response-time guarantees, priority fixes, training |

**Pricing:** message Thanh on [Facebook](https://www.facebook.com/thanhtt88) for a quote.
