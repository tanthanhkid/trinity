## Đã sửa trong lần chạy

Server Rust:
- Lỗi thiếu quyền ở `create_record`/`update_record` (và các tool dùng `require_perm`) trả câu chung, mất tên quyền thiếu.
  Node trả nguyên `ForbiddenException.message` ("... cần quyền custom_records.manage"). `mod-mcp/src/exec.rs` giờ chuyển
  tiếp thông điệp này; 403 khác vẫn là câu chung. Có thêm ca vào `tests/mcp_contract.rs`.

Test lệch (có bằng chứng):
- Tool `list_structure_versions`/`restore_structure_version` có từ sau khi `run.mjs` viết; regex `structure` coi nhầm
  chúng là tool xoá. Chỉ còn cấm `delete|remove|drop`.
- `server/contracts/mcp/tools.json` đặt `confirmed_by_user` bắt buộc cho `create_objects`, `create_object`,
  `install_object_template`; các ca âm của `run-roles.mjs` gọi thiếu nên bị SDK từ chối `-32602` trước khi tới kiểm quyền.
- `setup-users.mjs`/`setup-users-roles.mjs` chỉ cho host Neon: thêm `E2E_ALLOW_LOCAL_DB=1` (chỉ localhost/127.0.0.1,
  `run-rust.sh` đặt). Vai nguồn "Nhân viên kinh doanh" chỉ có ở bản demo; `seed --sample` đặt tên "Sale", giờ chấp nhận cả hai.
- Bảng `hoc_sinh` chỉ có ở demo Neon: `setup-fixture.mjs` dựng bằng `create_objects` trên DB trống.
- `/.well-known/oauth-*` ở gốc hiện do rewrite của Next/strangler sang Node (PLAN 4.14; Rust tự trả ở X06). Với `E2E_RUST=1`
  (`run-rust.sh` đặt) `run.mjs` kiểm đúng đường Rust có: `/api/v1/oauth/protected-resource` và
  `/api/v1/oauth/.well-known/oauth-authorization-server`. Ở X06 cần bỏ ngoại lệ này và kiểm lại đường ở gốc.

## Lần chạy bổ sung (27/11/2026 chiều, binary build từ origin/main 1cec6bd1 + PR này)

`run-rust.sh` giờ chạy thêm `tools-sweep.mjs` và `server/scripts/smoke-mcp.sh` (curl thuần: login, DCR, PKCE, `tools/list`, gọi tool).
Kết quả: `run.mjs` 19/19, `run-roles.mjs` 29/29, `smoke-mcp.sh` OK (110 tool, nhóm đăng bài 25), `tools-sweep.mjs` xanh.
`tools-sweep.mjs`: `tools/list` = 110 tool, tên khớp `contracts/mcp/tools.json`; gọi MỖI tool một lần với đối số tối thiểu dựng từ
`inputSchema` (40 tool đọc ok + 13 lỗi nghiệp vụ; 8 tool ghi ok + 48 lỗi nghiệp vụ, vd thiếu cấu hình kênh/không thấy bản ghi). Đỏ khi
tool trả "chưa sẵn sàng", lỗi nội bộ, hoặc kết quả sai `outputSchema` (SDK từ chối). Trần 60 lời gọi/phút/người được chờ qua, không tính lỗi.

Lỗi Rust tìm được và sửa:
- `list_deals` trả thêm khoá `code` trong mỗi deal, trái `outputSchema` đóng băng (`additionalProperties: false`) ⇒ client SDK
  từ chối cả kết quả. Bỏ khoá; `mcp_pg` kiểm khoá từng deal.
- `complete_setup` chưa đăng ký (trả "chưa sẵn sàng"). Đăng ký trong `register_group3` (scope `crm.write`, quyền
  `custom_objects.manage`), dùng `mod_setup::status`: dang_dung → da_dung, chua_dung bị từ chối như `POST /setup/complete`. Có test pg.

Còn lại (đã biết, không sửa ở PR này): tool `link_records` chưa đăng ký trên Rust (cần port logic liên kết theo mã); sweep ghi nhận là
"đã biết", đặt `E2E_STRICT=1` để coi là đỏ. 5/8 ca `crates/mod-mcp/tests/mcp_pg.rs` (`--ignored`) đỏ sẵn trên main trước PR này
(lệch dữ liệu mẫu, `confirmed_by_user` thiếu ở ca cũ...): không do PR này.

## Phần cần model: chưa chạy (SKIP có chủ đích)

`claude-code-roles.mjs` cần `claude` đăng nhập (khoá/quota AI; không tạo/dùng khoá nào trong lần chạy này). `run-rust.sh` in dòng
`SKIP` rõ ràng khi không bật; bật lại bằng `--with-model` hoặc `E2E_WITH_MODEL=1`. Chạy sau khi chủ dự án cho phép, 5 lần mỗi bên để so với Node:

```
DATABASE_URL=... tests/mcp-e2e/run-rust.sh --with-model --runs 5
```

Tiêu chí cứng: 0 lời gọi tool bị từ chối vì schema (script đếm trong log); tỉ lệ hoàn thành chỉ để tham khảo.
